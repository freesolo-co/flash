flash cli

A standardized output theme for every command

One visual language across the whole CLI: a brand header, colored status badges, aligned tables, key/value panels, and syntax-highlighted JSON. The themed view renders on an interactive terminal; piped or scripted output stays byte-for-byte plain, so jq, scripts, and the agent contract are untouched.
